# بازی استراتژیک: جنگ بزرگ ایران و آمریکا

این یک بازی استراتژیک نوبتی ساده است که در آن بازیکنان کنترل نیروهای ایران یا آمریکا را به دست می‌گیرند.

## هدف بازی

هدف اصلی بازی، تصرف پایتخت کشور دشمن است.

## نحوه بازی (در حال توسعه)

- بازی به صورت نوبتی انجام می‌شود.
- در هر نوبت، بازیکن می‌تواند واحدهای خود را حرکت داده و به نیروهای دشمن حمله کند.
- هر واحد نظامی دارای قدرت حمله، دفاع و میزان حرکت مشخصی است.
- برای پیروزی، پایتخت دشمن را تصرف کنید!

## راه‌اندازی

برای اجرای بازی، فایل `index.html` را در مرورگر وب خود باز کنید.
